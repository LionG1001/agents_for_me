# 视频与多模态输入链路优化

用于取数长尾、CPU增强、共享解码缓存或VAE等前处理分组。分组大小、workers、预取和缓存限额均由实际负载确定；以下方法不规定某个项目的默认参数。

## 1. 从迟到batch定位阶段

先对齐训练的`DataLoader.next`等待与rank、worker、batch/sample ID、时间区间，再按需要下钻：原始读取、解码、resize、样本构造、随机增强、collate、进程间传递和设备搬运。`next()`慢只说明消费端在等待，不能直接归因于存储或通信；缓存命中快也不能证明整个样本构造快。

记录慢batch的阶段耗时、CPU占用和内存活动，检查是否周期性由同一worker供数不及。按实际调度比较worker准备一个batch的时间与该worker再次被消费前的时间，不假定所有加载器都严格轮转。预取可以缓冲突发，不能替代持续生产能力；增加workers还可能放大CPU、内存带宽和共享存储争用。

minor faults反映无需从磁盘读入的缺页处理，不能单独证明磁盘/NFS读取；结合阶段时间、I/O与CPU证据判断。诊断期间重CPU探针、并行单测或profiler可能改变瓶颈；最终A/B使用一致的轻量观测，避免把受干扰运行作为干净基线。

## 2. 分块增强保留输入与随机语义

大段帧同时进行cast、颜色变换或布局转换时，可评估分块以缩小中间张量和内存流量。先确认计算在分块维度上独立；跨帧统计、时序状态或跨视角耦合不能直接切块。

核对原始随机契约：同一视频的帧/视角是否共享裁剪和颜色参数，调用方RNG应推进几次。可先采样参数再复用，或在接口允许时复制随机状态；不能让每块重新采样，也不能因复用参数少推进了后续样本所需的随机状态。

验证应覆盖输出像素和调用结束后的RNG状态，以及样本/帧/视角顺序。选取实际训练/评估路径、尾块、不同输入布局、支持的随机生成器和只读数组；仅sample ID一致不足以证明增强一致。

分块参数在进入worker前检查合法性；整数参数要区分布尔、浮点和整数，关闭值语义明确。只读mmap/view转为PyTorch共享内存tensor前检查API要求，必要时复制可写缓冲；正常可写输入不因此一律复制。检查拼接和复制成本是否抵消局部收益，保留原路径以便A/B。

## 3. 共享确定性解码缓存

优先缓存确定性的解码/resize结果，随机增强保持原执行位置。缓存随机结果需要另行定义RNG、复用和失效契约，不能默认为静态数据。

实现与验收按实际共享范围选择：

- **身份与失效**：key覆盖源内容或可信不可变版本、解码器及相关库版本、resize等变换设置。文件名/大小/mtime相同不保证内容相同；源可能变化时，检查哈希、等待锁和解码期间的替换，必要时读取不可变快照。metadata检查不能宣称能防止所有并发修改。
- **同key并发**：互斥构建同一条目，临时文件完成后原子发布，读者不得读到半成品。定义校验、损坏条目处理和失败行为，不将损坏或变化的源静默当作有效命中。
- **容量与锁范围**：全局配额锁只处理核算、预留等共享状态；独立大文件写入可放到逐key锁内、全局锁外。并发写先预留，防止各进程重复花费同一空闲容量；账本拒绝负数及截断记录。
- **中断与容量满**：定义临时文件、失败预留与回收规则。保守保留配额时说明可能提前停止缓存；容量不足可返回等价的即时解码，不在活跃任务中随意删除缓存或重置账本。
- **真实文件系统**：跨节点复用时验证目标共享存储的锁、原子发布和容量行为，本地多进程测试不能替代跨节点测试。节点本地缓存则逐节点核算容量。

分别记录应用缓存、OS/共享文件系统客户端页缓存和编译/autotune缓存状态；新建空解码目录不等于所有缓存均冷。冷/暖缓存都验证像素与顺序，再测计时；收益需覆盖哈希、锁、读写、首建和容量满后的行为，不能只测命中函数。

## 4. 独立样本前处理分组

VAE等模块逐样本调用时，可评估沿batch分组以减少小调用开销。先确认样本间独立，检查BatchNorm、随机层、时序特征缓存及其创建/重置生命周期；不能把跨样本状态混入分组。

保留样本顺序、帧数、分辨率及输出结构；不以减少有效输入制造加速。用真实输入验证原路径与分组路径的数值、尾组、峰值显存及错误行为；前处理不参与梯度时不人为要求其反向，参与训练的路径则验证反向。非目标device、tiled等模式保留已有路径或另行验证，不因普通编码通过就扩大支持范围。

分组大小属于执行配置，和训练microbatch/GBS分别记录。显存允许更大分组也不代表整步更快；与数据缓存同时变化时只能报告组合收益。

## 5. 采纳与验收

局部解码、增强或编码变快后，回到目标训练的同配置A/B：看整步均值、尾部、所有rank的等待分布和资源占用。以吞吐为目标时，复跑中整步收益小于波动的相机并行、预取或融合候选保持可选，不因为第一次较快就改通用默认；显存等其他目标另按其指标验收。

按用户目标保留最终组合的较长验证，分段观察后程取数等待与资源变化；短程配对收益与长跑持续性能分列。只有优化后长跑而没有同轮关闭对照时，不补称长跑独立消融。原始探针与机器信息留在实验区，正式实现不依赖实验脚本。
